AI CENTRE 2 · BANDIT V2 · API VERSION 1.0 · 2026-08-20

多语言音频分离 API

从音频或视频中异步提取影视对白、音乐、音效和背景四条音轨，结果自动上传 OSS。

生产地址：https://aicentre2.sligenai.cn:8443　Swagger　OpenAPI JSON

直接调用请求字段查询任务等待接口取消代码示例错误码格式与安全

接口输出

speech_url影视对白
music_url音乐
sfx_url环境声和音效
background_url音乐与音效合成背景

四个结果均为公网 HTTPS OSS URL，输出为48kHz、双声道、PCM16 WAV，并应用 -1 dBFS 峰值保护。歌唱通常进入 music，本接口定位是影视对白分离，不是歌曲人声提取。

1. 最快开始

<SERVICE_TOKEN> 是占位符。实际 Token 由 AI Centre 管理员单独发送，不会写入公网文档。鉴权值必须是 Bearer + 空格 + Token。

设置环境变量

export BASE='https://aicentre2.sligenai.cn:8443'
export SERVICE_TOKEN='粘贴管理员分配的Token'

POST创建异步音频分离任务

下面的测试素材已在生产环境验证，填入实际 Token 后可以直接执行：

curl --location --request POST "$BASE/v1/audio-separation/jobs" \
  --header "Authorization: Bearer $SERVICE_TOKEN" \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "source_uri": "https://bucket-silge-internal-products.oss-cn-shenzhen.aliyuncs.com/BE2.6/test4.wav",
    "model": "bandit-v2-multilingual",
    "filename_prefix": "order-001",
    "external_ref": "order-001",
    "metadata": {"business": "demo"}
  }'

202响应

{
  "job_id": "0ca30251-7006-4663-a27b-813dc07a0089",
  "status": "queued",
  "priority": 5,
  "model": "bandit-v2-multilingual",
  "status_url": "/v1/audio-separation/jobs/0ca30251-7006-4663-a27b-813dc07a0089"
}

2. 请求字段

字段类型必填默认值说明
source_uristring是—公网HTTPS音频或视频URL，最长4096字符；支持OSS签名参数。
modelstring否bandit-v2-multilingual当前只允许该值。
filename_prefixstring否separated结果文件名前缀，1～128字符，不能包含斜杠或反斜杠。
external_refstring/null否null调用方订单号等外部引用，最长256字符。
run_idstring/null否null调用方运行ID，最长256字符。
campaign_idstring/null否null活动ID，最长256字符。
project_idstring/null否null项目ID，最长256字符。
metadataobject否{}调用方自定义结构化元数据。

未列出的字段会返回422，不会被静默忽略。

3. 查询任务

GET/v1/audio-separation/jobs/{job_id}

export JOB_ID='把创建接口返回的job_id粘贴到这里'
curl --location "$BASE/v1/audio-separation/jobs/$JOB_ID" \
  --header "Authorization: Bearer $SERVICE_TOKEN"

Bash自动轮询

while true; do
  RESULT="$(curl --silent --show-error \
    --header "Authorization: Bearer $SERVICE_TOKEN" \
    "$BASE/v1/audio-separation/jobs/$JOB_ID")"
  STATUS="$(printf '%s' "$RESULT" | jq -r '.status')"
  printf 'status=%s\n' "$STATUS"
  if [ "$STATUS" = 'succeeded' ] || [ "$STATUS" = 'failed' ] || [ "$STATUS" = 'cancelled' ]; then
    printf '%s\n' "$RESULT" | jq .
    break
  fi
  sleep 2
done

4. 提交并等待结果

POST/v1/audio-separation/jobs/wait

请求字段与异步接口完全相同。该接口使用更高队列优先级，完成后直接返回四条OSS URL。

curl --location --max-time 3700 \
  --request POST "$BASE/v1/audio-separation/jobs/wait" \
  --header "Authorization: Bearer $SERVICE_TOKEN" \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "source_uri": "https://bucket-silge-internal-products.oss-cn-shenzhen.aliyuncs.com/BE2.6/test4.wav",
    "model": "bandit-v2-multilingual",
    "filename_prefix": "wait-demo"
  }'
等待超过服务器时限会返回504，并在 detail 中提供 job_id 和 status_url。任务不会被取消，请继续调用查询接口。

5. 取消任务

POST/v1/audio-separation/jobs/{job_id}/cancel

curl --location --request POST \
  "$BASE/v1/audio-separation/jobs/$JOB_ID/cancel" \
  --header "Authorization: Bearer $SERVICE_TOKEN"

取消是尽力而为：排队任务通常可以取消；已经进入GPU推理或上传阶段的任务可能仍然完成。

6. Python完整示例

import os
import time
import requests

base = "https://aicentre2.sligenai.cn:8443"
headers = {"Authorization": f"Bearer {os.environ['SERVICE_TOKEN']}"}

created = requests.post(
    f"{base}/v1/audio-separation/jobs",
    headers=headers,
    json={
        "source_uri": "https://bucket-silge-internal-products.oss-cn-shenzhen.aliyuncs.com/BE2.6/test4.wav",
        "model": "bandit-v2-multilingual",
        "filename_prefix": "python-demo",
        "external_ref": "order-python-001",
    },
    timeout=30,
)
created.raise_for_status()
job_id = created.json()["job_id"]

while True:
    response = requests.get(
        f"{base}/v1/audio-separation/jobs/{job_id}",
        headers=headers,
        timeout=30,
    )
    response.raise_for_status()
    result = response.json()
    if result["status"] == "succeeded":
        print(result["speech_url"])
        print(result["music_url"])
        print(result["sfx_url"])
        print(result["background_url"])
        break
    if result["status"] in {"failed", "cancelled"}:
        raise RuntimeError(result)
    time.sleep(2)

7. 状态码与处理

HTTP含义调用方处理
200查询、等待或取消成功读取JSON。
202异步任务已接收保存 job_id，每2～5秒轮询。
401Token缺失或无效检查 Bearer 前缀及Token。
404任务不存在或记录过期检查任务ID；查询记录默认保留7天。
413素材超过512MiB缩小素材后重试。
415格式不支持或类型冲突修复Content-Type或重新编码。
422URL或字段无效修正请求，不要原样重试。
502下载、处理、推理或上传失败检查源URL有效期，必要时退避重试。
503队列或服务暂不可用按2、5、10秒退避重试。
504等待或源站下载超时有job_id则继续查询，否则检查源站。

8. 素材格式、安全与性能

视频：MP4、MOV、MKV、WebM　　音频：WAV、MP3、M4A、AAC、FLAC、OGG

  • 只接受公网HTTPS URL，可以携带签名参数；不接受本地文件路径或公网multipart。
  • 禁止本机、内网、云元数据地址、URL用户名密码和fragment。
  • 后缀不区分大小写，并结合Content-Type与文件头判断真实格式。
  • 不要在日志中记录生产Token或完整OSS签名URL。
  • 建议保存调用方 external_ref 与中台 job_id 的对应关系。
生产实测：10.274833秒WAV的纯推理约2.04秒，RTF约0.199；包含下载、初始化和四轨上传的端到端时间约8～11秒。该数据用于容量估算，不构成固定SLA。
