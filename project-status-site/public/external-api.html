公开接口只接收公网 HTTPS 素材 URL，不接收本地文件或 multipart 上传。除健康检查外，统一发送 Authorization: Bearer <SERVICE_TOKEN>。
SERVICE_TOKEN直接开始接口分类语音识别唇形驱动语音合成OCR人脸处理视频深度音频分离视频超分MiniMax H3错误码

SERVICE_TOKEN 获取与正确填写

<SERVICE_TOKEN> 是占位符，不是可以直接发送的文字。Token 由 AI Centre 管理员单独分配，出于安全原因不会写入这个公网网页。交付第三方时，请通过私聊或密码管理器单独发送。

鉴权必须包含 Bearer 前缀，前缀与 Token 之间有一个空格。

结果Authorization 请求头
正确Authorization: Bearer 实际SERVICE_TOKEN
错误Authorization: 实际SERVICE_TOKEN
export SERVICE_TOKEN='粘贴管理员单独发给你的Token'
curl -H "Authorization: Bearer ${SERVICE_TOKEN}" \
  "https://aicentre2.sligenai.cn:8443/v2/tts/providers"

一、用本地素材直接开始

本次示例原文件：

K:\三瑞集团：尊爱AI视频需求汇总\视频脚本\脚本1\女1.mp4
K:\三瑞集团：尊爱AI视频需求汇总\视频脚本\脚本1\女1.MP3

先裁剪前 10 秒，原文件不会被覆盖：

ffmpeg -ss 0 -i "K:\三瑞集团：尊爱AI视频需求汇总\视频脚本\脚本1\女1.MP3" `
  -t 10 -map 0:a:0 -c:a libmp3lame -q:a 2 `
  "K:\三瑞集团：尊爱AI视频需求汇总\视频脚本\脚本1\女1_前10秒.mp3"

把视频和新音频上传到你自己的对象存储，取得公网 HTTPS URL，然后设置以下 PowerShell 变量。K:\... 本地路径不能直接放进 JSON。

$Base = "https://aicentre2.sligenai.cn:8443"
$Token = "替换为分配给你的SERVICE_TOKEN"
$VideoUrl = "https://你的对象存储.example.com/女1.mp4?签名参数"

$Headers = @{ Authorization = "Bearer $Token" }

三、语音识别

POST通过音视频 URL 识别文字

language 可省略或传 auto，都会自动识别语种；已知语种时也可明确传 zh、en 等代码。

$Body = @{file_url=$AudioUrl; language="auto"; beam_size=5} | ConvertTo-Json
$Asr = Invoke-RestMethod -Method Post -Uri "$Base/v1/asr/transcriptions" `
  -Headers $Headers -ContentType "application/json" -Body $Body -TimeoutSec 900
$Asr.segments | Select-Object start,end,text
$Asr | ConvertTo-Json -Depth 20 | Set-Content -Encoding utf8 ".\女1_前10秒_ASR.json"

响应包含识别语言、媒体时长、分段文字及逐字时间信息。

四、唇形驱动

POST通过视频和音频 URL 创建唇形驱动任务

$Body = @{video_url=$VideoUrl; audio_url=$AudioUrl; face_restore=$true} | ConvertTo-Json
$Created = Invoke-RestMethod -Method Post -Uri "$Base/v1/lipsync/jobs" `
  -Headers $Headers -ContentType "application/json" -Body $Body -TimeoutSec 900
$JobId = $Created.job_id
$Created

轮询并下载结果

do {
  Start-Sleep -Seconds 3
  $Job = Invoke-RestMethod -Uri "$Base/v1/lipsync/jobs/$JobId" -Headers $Headers
  Write-Host "$($Job.state) / $($Job.stage)"
} while ($Job.state -in @("queued", "running"))

if ($Job.state -eq "completed") {
  Invoke-WebRequest -Uri $Job.result_url -OutFile ".\女1_唇形驱动_GFPGAN.mp4"
} else { throw $Job.error }

任务完成后，响应中的 result_url 是可直接访问的 OSS HTTPS 地址，无需再拼接中台本地路径。原来的鉴权下载接口仍保留作为兜底。

}

五、语音合成

POST普通语音合成

$Body = @{text="您好，这是语音合成示例。"; language="auto"; voice_profile_id="default"; provider="auto"} | ConvertTo-Json
Invoke-WebRequest -Method Post -Uri "$Base/v2/tts/speech" -Headers $Headers `
  -ContentType "application/json" -Body $Body -OutFile ".\普通语音合成.wav" -TimeoutSec 900

POSTVoxCPM2 深度语音克隆

参考音频可选；提供 reference_audio_url 时强制走 VoxCPM2。clone_mode 支持 auto / controllable / ultimate，emotion_strategy 支持 auto / inherit / force。跨语言会自动使用隔离 Reference/Controllable 模式，参考文本只参与语言检测和质量审计，不送入 continuation；长参考会自动选择代表性约5秒。情绪一致时继承参考表达，冲突时才注入风格。同步请求先生成常规候选，仅在正文、首尾或 ERes2NetV2 说话人门禁失败时追加受控 seed，跨语言最多六个候选；隔离参考的中文中长句按逗号短语分段，减少音色漂移。最终选择正文、音色、情绪和首尾均更稳的结果，不使用可能引入额外发声的前导词。prosody.speed/volume/pitch 均真实生效。

$Body = @{
  text="这段文字将使用参考音频进行深度语音克隆。"
  voice_profile_id="default"
  reference_audio_url=$AudioUrl
  prompt_text="参考音频中准确说出的文字"
  emotion="真诚、温暖、有感染力"
  emotion_enhance=$false
  clone_mode="auto"
  emotion_strategy="auto"
  prosody=@{speed=1.0; volume=1.0; pitch=1.0}
  quality_mode="standard"
} | ConvertTo-Json
Invoke-WebRequest -Method Post -Uri "$Base/v2/tts/speech" -Headers $Headers `
  -ContentType "application/json" -Body $Body -OutFile ".\VoxCPM2_克隆.wav" -TimeoutSec 900

实际路由见响应头：X-TTS-Clone-Mode、X-TTS-Clone-Fallback、X-TTS-Reference-Language、X-TTS-Target-Language、X-TTS-Emotion-Strategy、X-TTS-Candidate-Count、X-TTS-Reference-Window、X-TTS-Reference-Fallback。

POST实时 PCM 流式合成

请求体与同步接口相同，只支持 quality_mode=standard。跨语言流式使用最佳参考片段单次生成；响应为 48kHz、16-bit、小端、单声道 PCM；使用响应头 X-TTS-Request-ID 查询最终质量审计。

curl -N -X POST "$BASE/v2/tts/speech/stream" \
  -H "Authorization: Bearer $SERVICE_TOKEN" -H "Content-Type: application/json" \
  -d '{"text":"这是实时流式语音。","emotion":"自然、亲切","prosody":{"speed":1.1,"volume":1.0,"pitch":1.0}}' \
  --output speech.pcm
ffplay -f s16le -ar 48000 -ac 1 speech.pcm

POST最多20000字符的异步长语音

同步和流式接口最多5000字符；POST /v2/tts/jobs 最多支持20000字符，服务端自动分段、最多预生成2段、顺序合并并上传OSS。支持普通TTS和带 reference_audio_url 的VoxCPM2深度克隆；长语音固定使用 quality_mode=standard，失败分段独立重试。

python - <<'PY'
import json
text = "这是需要合成的长文本。" * 800
with open("long-tts-request.json", "w", encoding="utf-8") as file:
    json.dump({
      "text": text, "language": "zh", "voice_profile_id": "default",
      "provider": "auto", "quality_mode": "standard",
      "reference_audio_url": "https://你的对象存储.example.com/reference.MP3",
      "prompt_text": "参考音频准确文本",
      "prosody": {"speed": 1.0, "volume": 1.0, "pitch": 1.0},
      "idempotency_key": "order-20260820-long-001"
    }, file, ensure_ascii=False)
PY
curl -X POST "$BASE/v2/tts/jobs" \
  -H "Authorization: Bearer $SERVICE_TOKEN" -H "Content-Type: application/json" \
  --data-binary @long-tts-request.json

GET /v2/tts/jobs/{job_id} 查询进度；完成后 result.audio_url 是公网OSS WAV。GET /v2/tts/jobs/{job_id}/audio 保留为鉴权下载。相同的8～256字符 idempotency_key 会复用原任务。

七、人脸处理

POST提交人脸处理并等待 OSS 结果（推荐）

HTTP 长连接等待内部高优先级任务完成，成功后直接返回 OSS video_url，客户端无需轮询。客户端超时请设置为至少 1800 秒。

$Body = @{source_uri=$VideoUrl; filename="face_mosaic.mp4"; external_ref="order-001"; metadata=@{}} | ConvertTo-Json
$FaceResult = Invoke-RestMethod -Method Post -Uri "$Base/v1/face-mosaic/jobs/wait" `
  -Headers $Headers -ContentType "application/json" -Body $Body -TimeoutSec 1800
$FaceResult.video_url
{
  "job_id": "任务UUID",
  "status": "succeeded",
  "video_url": "https://oss.example.com/path/face_mosaic.mp4",
  "applied": true,
  "analysis": {}
}

等待超时返回 504 时任务仍继续执行，响应会包含 job_id，可用原查询接口继续查询。

POST通过视频 URL 创建人脸处理任务

$Body = @{source_uri=$VideoUrl; filename="face_mosaic.mp4"; external_ref="order-001"; metadata=@{}} | ConvertTo-Json
$Face = Invoke-RestMethod -Method Post -Uri "$Base/v1/face-mosaic/jobs" `
  -Headers $Headers -ContentType "application/json" -Body $Body -TimeoutSec 900

GET /v1/face-mosaic/jobs/{job_id} 查询，POST /v1/face-mosaic/jobs/{job_id}/cancel 取消。

八、SceneDetect 视频切片

输入公网 HTTPS 视频 URL，默认使用 ContentDetector：threshold=27.0、min_scene_len=15 帧。每个切片都会上传 OSS。

POST普通异步任务（优先级 5）

$SceneBody = @{
  source_uri=$VideoUrl
  filename="scene.mp4"
  threshold=27.0
  min_scene_len=15
  external_ref="order-001"
  metadata=@{}
} | ConvertTo-Json
$SceneJob = Invoke-RestMethod -Method Post -Uri "$Base/v1/video-scenes/jobs" `
  -Headers $Headers -ContentType "application/json" -Body $SceneBody
$SceneJob.job_id

GET /v1/video-scenes/jobs/{job_id} 查询，POST /v1/video-scenes/jobs/{job_id}/cancel 取消。

服务端内部仍异步执行，但 HTTP 请求等待完成，建议客户端超时至少 1800 秒。

$SceneResult.scenes | Select-Object index,start_seconds,end_seconds,duration_seconds,video_url

九、DA2 / DA3 单目视频深度推理

支持 DA2（Video Depth Anything）与 Depth Anything 3，均可选择 Small/Base。输入公网 HTTPS 视频 URL，输出时序一致的灰度深度 MP4 和可直接访问的 OSS URL。

curl -X POST "$BASE/v1/video-depth/jobs" \
  -H "Authorization: Bearer $SERVICE_TOKEN" -H "Content-Type: application/json" \
  -d '{"source_uri":"https://storage.example.com/video/source.mp4","version":"da2","model":"small","filename":"depth.mp4","input_size":518,"max_resolution":960,"target_fps":-1}'

version 可选 da2/da3，model 可选 small/base；默认 DA2 Small。input_size 必须是14的倍数（224～756）；生产 GPU 上 DA2 Base 超过392会自动降为392，并在响应中返回实际尺寸。max_resolution 默认960；target_fps=-1保持原帧率。使用 GET /v1/video-depth/jobs/{job_id} 查询，POST /v1/video-depth/jobs/{job_id}/cancel 取消。需要直接等待结果时提交到 /v1/video-depth/jobs/wait。

十、音频分离

使用 Bandit v2 DnR v3 Multilingual，把音频或视频分成影视对白、音乐、音效，并返回组合背景轨。输入只接受公网 HTTPS URL。

$Body = @{
  source_uri=$VideoUrl
  model="bandit-v2-multilingual"
  filename_prefix="campaign-001"
  external_ref="order-001"
  metadata=@{}
} | ConvertTo-Json
$Job = Invoke-RestMethod -Method Post -Uri "$Base/v1/audio-separation/jobs" `
  -Headers $Headers -ContentType "application/json" -Body $Body
$Job.job_id

GET /v1/audio-separation/jobs/{job_id}查询，POST /v1/audio-separation/jobs/{job_id}/cancel取消。需要保持连接直接等待结果时使用POST /v1/audio-separation/jobs/wait。

{
  "status": "succeeded",
  "speech_url": "https://oss.example.com/audio/campaign-001_speech.wav",
  "music_url": "https://oss.example.com/audio/campaign-001_music.wav",
  "sfx_url": "https://oss.example.com/audio/campaign-001_sfx.wav",
  "background_url": "https://oss.example.com/audio/campaign-001_background.wav",
  "duration_seconds": 32.829,
  "rtf": 0.1033
}

speech表示影视对白，歌唱声通常进入music；background等于音乐与音效组合。四个结果均为48kHz双声道PCM WAV，并应用-1dBFS峰值保护。

十一、视频超分

默认provider=auto，依次使用FlashVSR V2、FlashVSR、SeedVR2。长视频自动切成不超过12秒的片段，最多3片并发超分；失败片段独立重生，不重跑成功片段。全部成功后按原顺序无转场合并并恢复原始音轨。

curl -X POST "$BASE/v1/video-upscale/jobs" \
  -H "Authorization: Bearer $SERVICE_TOKEN" -H "Content-Type: application/json" \
  -d '{"source_uri":"https://storage.example.com/video/source.mp4","provider":"auto","max_resolution":1920,"external_ref":"order-001","metadata":{}}'

provider支持auto / flashvsr_v2 / flashvsr / seedvr2。查询：GET /v1/video-upscale/jobs/{job_id}；取消：POST /v1/video-upscale/jobs/{job_id}/cancel；等待模式：POST /v1/video-upscale/jobs/wait。

十二、MiniMax H3多机视频生成

固定受控H3工作流，支持纯文本生成，也支持单段/两段、可选参考图、参考视频、参考音频和Worker故障转移。Prompt按请求原文传递，不允许提交任意ComfyUI工作流。

curl -X POST "$BASE/v1/video-generations/minimax-h3/jobs" \
  -H "Authorization: Bearer $SERVICE_TOKEN" -H "Content-Type: application/json" \
  -d '{
    "segment_mode":"single",
    "prompts":["一只雄鹰在黑夜中飞过雪山，电影级光影"],
    "duration_seconds":5,
    "quality":"medium",
    "resolution":"480p",
    "aspect_ratio":"9:16",
    "priority":500,
    "seed":482901731,
    "external_ref":"order-001",
    "metadata":{}
  }'

参考图、参考视频、参考音频均为可选URL列表，全部留空时为纯文本生成。默认单段、720P、9:16、5秒、中质量；清晰度支持480P/720P/1080P，比例支持9:16、16:9、1:1、4:3、3:4，时长范围2～15秒。quality支持low / medium / high：低档快速预览，中档为默认生产流程，高档使用质量采样器且耗时明显增加；兼容midia并归一化为medium。两段模式仍要求参考视频总长4～30秒、每段2～15秒及两条Prompt。priority范围1～1000、默认500，数值越高越先获得下一台空闲Worker，同优先级按提交时间处理，但不会中断已运行任务。

GET  /v1/video-generations/minimax-h3/jobs/{job_id}
GET  /v1/video-generations/minimax-h3/jobs/{job_id}/queue-position
GET  /v1/video-generations/minimax-h3/workers/status
POST /v1/video-generations/minimax-h3/jobs/{job_id}/cancel

排队接口的ahead_count表示前面还有多少个任务；Worker状态接口返回在线、空闲、忙碌、离线、停用、排空和不兼容机器数量。完成结果中的result_url和part_urls均为OSS URL。
