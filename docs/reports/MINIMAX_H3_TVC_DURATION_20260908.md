# MiniMax H3 产品TVC时长与参考图 A/B 测评

日期：2026-09-08  
品类：面膜、精华液  
生成入口：AI Centre生产API  
配置：单段、9:16、4步Turbo、Euler、24fps；同品类固定Seed

## 结论

1. 生产Euler链路没有复现16分钟耗时。5秒为127～156秒，10秒为262～268秒，15秒为397～443秒，基本按帧数线性增长。
2. 本轮生产API成片实际为`720×1280`，不是直连Comfy实验的`768×1344`。这说明线上预设与本地当前代码存在版本/口径差异；两个耗时不能直接混为同一配置。
3. 在纯文本生成中，10秒是本轮综合最稳定时长。5秒镜头信息不足，15秒容易发生产品形态漂移、液滴拉伸和场景语义漂移。
4. 加入单张干净SKU参考图后，10秒面膜和精华的产品识别、无字包装和英雄镜头均明显改善，且端到端耗时反而从约265秒降至203～210秒。本次只有单Seed，不能把速度差异解释为参考图必然加速。
5. 当前H3适合做“单一产品、一个主要动作、一个英雄镜头”的5～10秒素材。15秒商业TVC更适合拆成三个受控5秒镜头后剪辑，不应让模型在单次15秒内自行完成多镜头叙事。

主要缺陷：

- 纯文本面膜5秒误生出泵瓶，画面过亮且膜布像窗帘。
- 面膜15秒发生膜布、半球、器皿之间的形态漂移，不能直接交付。
- 纯文本精华5秒生成伪文字，即使Prompt要求无字也不能稳定避免。
- 精华10/15秒出现液滴异常拉长、瓶口与滴管比例变化，物理真实性不足。
- 参考图版本消除了明显伪标签并改善了产品收尾，但精华瓶在近景中仍有胖瘦变化，液滴仍需逐帧门禁。

## 推荐生产流程

1. SKU参考图改为必选：正面全貌、无反光遮挡、无伪字；关键产品可提供正面和45度两张参考。
2. 单次镜头控制在5～10秒，只描述一个主要物理动作。面膜“舒展”和包装英雄镜头应拆开；精华“开瓶、滴落、复位”不应全部压在一个长镜头。
3. 15秒TVC采用3×5秒镜头：建立镜头、材质微距、英雄定格。逐段通过门禁后剪辑，最后统一配乐和声音设计。
4. 产品文字不要交给生成模型。包装在H3中保持无字，真实品牌、成分和卖点在后期使用矢量图层合成。
5. 自动门禁加入：参考图嵌入相似度、包装轮廓IoU、目标数量、伪文字检测、帧间产品形变、液体逆重力/异常拉伸、曝光剪切和黑帧。
6. 生产升级门槛：商业可用盲评均值不低于4.0/5；严重产品变形、伪文字、额外容器为0；参考产品相似度相对基线不下降；每档至少20次后再报告成功率和P95。
