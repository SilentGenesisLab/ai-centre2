# MiniMax H3 API 并发、素材类型与边界测试报告

测试时间：2026-09-02 02:22～02:31（Asia/Shanghai）  
生产接口：`https://aicentre2.sligenai.cn:8443/v1/video-generations/minimax-h3/jobs`  
结论：接口参数门禁、纯文本、参考图片、参考视频、1080P与15秒上限任务均可用；5个真实生成任务全部一次成功。

## 一、结论摘要

- 参数边界测试13项全部通过，预期状态码符合率100%。
- 纯文本、图片参考、视频参考三个2秒任务并发提交，全部返回202并一次生成成功。
- 15秒最大时长任务成功，端到端157.839秒，由RTX 5090 Worker执行。
- 1080P、16:9、2秒任务成功，端到端37.056秒，实际交付1920×1080。
- 三任务并发批次总完成时间96.965秒；执行期间两台RTX 4090 Worker实际参与调度。
- 接口校验路径在并发1/5/10/20下共完成200次请求，状态码正确率100%；并发20的P95为18.40ms。
- 发现三个需要后续处理的问题：Prompt单条长度没有上限、任务生成阶段进度长期停留25%、15秒纯文本任务与Prompt语义明显不一致。

当前正式契约：

- 单段时长：2～15秒。
- 清晰度：`480p | 720p | 1080p`。
- 比例：`9:16 | 16:9 | 1:1 | 4:3 | 3:4`。
- 纯文本生成：允许三个参考素材字段全部为空，但只支持`single`。
- 两段生成：必须提供参考视频，且必须恰好两条Prompt。
- 自定义模型尺寸：宽高必须同时提供、为32的倍数、单边不超过1344、总像素不超过1,048,576。
- 视频上限512MiB、图片上限20MiB、音频上限512MiB；下载超时900秒，单次Worker生成超时1800秒。

媒体容量上限本轮只核对了配置和门禁，没有实际下载512MiB素材，以免无必要占用公网带宽和对象存储。

## 九、发现的问题

### 1. Prompt缺少单条字符上限

当前只限制Prompt列表数量为1～2，并验证不能是空白字符串，但没有限制单条Prompt长度。超长文本可能导致请求体、数据库、ComfyUI或模型上下文不可控。建议增加5000字符硬上限，并在后台显示剩余字符数。

### 2. 生成进度过粗

15秒任务在绝大多数时间停留在`generating_part_1: 25%`，完成后直接跳到100%。后台看起来容易像卡死。建议读取ComfyUI WebSocket或历史节点进度，将采样、解码、渲染、上传映射为连续进度。

### 3. 长时纯文本语义失配

15秒任务技术上成功，但画面没有实现“星河”语义。建议增加抽帧视觉审核，至少在1秒、中点和结束前各取一帧，用图文相似度判定；低于门槛时自动以新Seed重试或标记`quality_failed`。

### 4. 有一次提交延迟异常

15秒边界“只提交后取消”用例曾出现6.586秒提交延迟，而其他正常提交约8～53ms。该异常没有在后续真实15秒任务中复现（46ms）。建议单独对成功入队路径连续测试30～100次，排查Redis/Celery控制命令、SQLite锁或取消任务带来的瞬时阻塞。

### 5. 结果质量与HTTP成功尚未分层

当前`succeeded`只代表生成、转码、上传成功，不代表主体一致、动作自然或Prompt语义正确。建议新增技术状态与质量状态双字段，避免调用方把HTTP/任务成功直接当作内容验收通过。
