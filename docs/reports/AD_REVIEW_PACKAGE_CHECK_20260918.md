## 发现的工程风险

1. `run-ad-review.mjs --check` 不验证远端 Ark/OSS 权限，只验证本地依赖和参考哈希。建议增加 `--check-remote`，用小文件上传、读取、删除和一次低成本模型权限探测。
2. 真实运行使用 `store: true`，目标视频、参考视频和音频分析会发送给 Ark 的 Responses API 并按供应商策略保存。若项目要求临时处理，应确认供应商是否支持 `store:false`，并增加配置开关。
3. 代理默认是 288 宽、3 FPS，适合整体审美和结构判断，不适合精确检查细小文字、逐帧闪烁和严格音画同步。报告已经在提示词中限制了这类结论，但生产接入应保留原片复核入口。
4. OSS 上传没有独立的请求超时控制，网络异常时可能长时间等待；建议为上传和删除增加 AbortController 超时。
5. 六项交付质检当前只接受公网 `videoUrl` 和 `imageUrl`，不会自动上传本地目标素材；调用方需要先完成上传或由后台提供受控上传入口。
