# GRSAI 五模型 TVC 图像测评报告

测试日期：2026-09-09（Asia/Shanghai）  
测试环境：AI Centre 生产控制面 → GRSAI  
样本规模：5个模型 × 4类素材，共20张，全部为1K档、单次生成。

## 结论

五个模型最终均完成四类素材生成，成功率20/20。基础版 `gpt-image-2.5` 的稳定性和综合商业可用性最好；`sunburst` 和 `flare` 平均速度最快，适合作为带明确光效风格的TVC关键帧候选；`nano-banana-2` 对指令和画面结构的响应较好，但本轮人物样本出现88.6秒长尾，不适合作为低延迟默认模型。

本报告每个模型、每类场景仅一个随机样本，视觉评分用于首轮选型，不等同于统计显著的最终模型排名。正式选型建议再做固定产品资产和人物参考图下的多Seed一致性测试。

## 视觉观察

- GPT Image 2：产品、人物与环境元素完整，商业摄影基线合格；光影和高级感相对保守。
- GPT Image 2.5：整体构图、人物皮肤和产品材质最均衡，四类场景波动最小，适合作为默认模型。
- Sunburst：暖色逆光和情绪氛围更突出，适合护肤、香氛、生活方式广告；强日光风格并不适合所有品牌视觉。
- Flare：生成速度最快，镜头高光风格更明确；用于纯白产品资产图时需要限制光晕，避免边缘和标签区域被干扰。
- Nano Banana 2：语义执行和产品主体保持较好，专用接口已工作；时延长尾明显，生产调度应设置独立超时与P95监控。

人物和产品资产仍需结合真实品牌Logo、包装文字、固定人物参考图继续测试。本轮“不含文字”的提示词不能证明模型对精确中文包装文字的能力。

## 接口兼容调整

- `nano-banana-2` 使用专用提交路径 `/v1/draw/nano-banana`，查询仍使用 `/v1/draw/result`。
- Nano Banana 2请求增加`imageSize`，AI Centre公网字段为`image_size`，支持`1K / 2K / 4K`。
- Sunburst和Flare要求像素尺寸，AI Centre自动将比例转换为对应像素；例如1K档`16:9`转换为`1344x768`。
- 调用方继续使用统一的 `/v1/image-generations/jobs`，无需感知GRSAI路径和参数差异。
